IDEA常用快捷键及快捷指令

MAC及windows按键对照

Mac 替换：Ctrl ➜ Command，Alt ➜ Option

快捷键

常用快捷键
快捷键 功能说明
Alt + Enter 导入包、自动修正代码、代码快速修复（重中之重）
Ctrl + Y 删除光标所在行
Ctrl + D 复制光标所在行，插入到下一行
Ctrl + Alt + L 格式化代码
Ctrl + / 单行注释 / 取消单行注释
Ctrl + Shift + / 选中代码多行块注释，再次按取消注释
Alt + Shift + ↑ / ↓ 上下移动当前代码行
Alt + Insert 生成 get/set、构造方法、toString 等代码
Shift + F6 批量重命名变量、方法、类（全局同步修改）
Ctrl + Alt + O 清除无用导入包
Ctrl + Alt + M 选中代码抽取为方法
完整快捷键
分类 快捷键 功能说明
代码编辑 Alt+Enter 导入包、自动修复、代码提示
Ctrl+Y 删除光标所在行
Ctrl+D 复制当前行到下一行
Ctrl+X 剪切当前行（无需选中）
Ctrl+Alt+L 格式化代码
Ctrl+/ 单行注释
Ctrl+Shift+/ 多行块注释
Alt+Shift+↑/↓ 移动当前代码行
Ctrl+Shift+↑/↓ 移动方法 / 代码块整体
Ctrl+Shift+Enter 补全语句，自动补分号大括号
Ctrl+Alt+O 删除未使用的 import 导入
Ctrl+W 向外扩大代码选中范围
Ctrl+Shift+W 缩小代码选中范围
Ctrl+Shift+U 选中内容大小写切换
代码生成重构 Alt+Insert 生成构造器、get/set、toString、重写方法
Ctrl+Alt+V 抽取局部变量
Ctrl+Alt+M 抽取方法
Ctrl+Alt+C 抽取常量
Shift+F6 批量重命名（全局所有引用同步变更）
查找替换 Ctrl+F 当前文件查找
Ctrl+R 当前文件替换
Ctrl+Shift+F 全局项目查找
Ctrl+Shift+R 全局项目替换
文件跳转阅读 Ctrl+B 跳转到定义
Ctrl+Alt+← 返回上一个光标位置
Ctrl+Alt+→ 前进下一个光标位置
Alt+← / → 切换标签页
Ctrl+E 查看最近打开文件列表
Ctrl+N 根据类名查找类
Ctrl+Shift+N 查找任意文件
Ctrl+P 查看方法参数提示
运行调试 Shift+F10 运行程序
Shift+F9 Debug 调试模式启动
F7 单步跳入方法
F8 单步跳过，执行下一行
F9 运行到下一个断点

快捷指令

常用指令
指令 类型 生成代码 解释 使用方式
psvm Live Template public static void main(String[] args) {} 快速生成 main 方法 输入 psvm → 按 Tab
sout Live Template System.out.println(); 标准输出 输入 sout → 按 Tab
soutv Live Template System.out.println("变量名 = " + 变量); 打印变量名和值 输入 soutv → 按 Tab
.var Postfix 类型 变量名 = 表达式; 自动提取变量 表达式末尾输入 .var → 按 Tab 或 Enter
.nn Postfix if (变量 != null) {} 非空判断 变量后输入 .nn → 按 Tab 或 Enter
.null Postfix if (变量 == null) {} 判空 变量后输入 .null → 按 Tab 或 Enter
.fori Postfix for (int i = 0; i < 集合.size(); i++) {} 带索引的 for 循环 集合变量后输入 .fori → 按 Tab 或 Enter
.for Postfix for (元素 : 集合) {} 增强 for 循环 集合变量后输入 .for → 按 Tab 或 Enter
.try Postfix try { } catch (Exception e) {} try-catch 表达式后输入 .try → 按 Tab 或 Enter
.if Postfix if (条件) {} 条件判断 布尔表达式后输入 .if → 按 Tab 或 Enter
ifn Live Template if (变量 == null) {} 判空 输入 ifn → 按 Tab
inn Live Template if (变量 != null) {} 非空 输入 inn → 按 Tab
.sout Postfix System.out.println(表达式); 打印表达式 表达式后输入 .sout → 按 Tab 或 Enter
.return Postfix return 表达式; 直接返回当前值 表达式末尾输入 .return → 按 Tab 或 Enter
完整指令
指令 类型 生成代码 解释 使用方式
psvm Live Template public static void main(String[] args) {} 快速生成 main 方法 输入 psvm → 按 Tab
main Live Template public static void main(String[] args) {} main 方法快捷方式 输入 main → 按 Tab
sout Live Template System.out.println(); 标准输出 输入 sout → 按 Tab
soutv Live Template System.out.println("变量名 = " + 变量); 打印变量名和值 输入 soutv → 按 Tab
soutp Live Template System.out.println("参数名 = " + 参数); 打印方法参数 输入 soutp → 按 Tab
serr Live Template System.err.println(); 错误输出 输入 serr → 按 Tab
.var Postfix 类型 变量名 = 表达式; 自动提取变量 表达式末尾输入 .var → 按 Tab 或 Enter
.field Postfix 提取为类的字段 将局部变量提升为成员变量 变量末尾输入 .field → 按 Tab 或 Enter
.return Postfix return 表达式; 直接返回当前值 表达式末尾输入 .return → 按 Tab 或 Enter
.cast Postfix (Type) 表达式 强制类型转换 表达式末尾输入 .cast → 按 Tab 或 Enter
fori Live Template for (int i = 0; i < ; i++) {} 普通 for 循环 输入 fori → 按 Tab
iter Live Template for (元素 : 集合) {} 增强 for 循环 输入 iter → 按 Tab
itco Live Template while (iterator.hasNext()) {} Iterator 遍历 输入 itco → 按 Tab
.for Postfix for (元素 : 集合) {} 基于集合生成 for-each 集合变量后输入 .for → 按 Tab 或 Enter
.fori Postfix for (int i = 0; i < 集合.size(); i++) {} 带索引的 for 循环 集合变量后输入 .fori → 按 Tab 或 Enter
.foreach Postfix 集合.forEach(元素 -> {}); Lambda 遍历 集合变量后输入 .foreach → 按 Tab 或 Enter
.while Postfix while (条件) {} while 循环 布尔表达式后输入 .while → 按 Tab 或 Enter
ifn Live Template if (变量 == null) {} 判空 输入 ifn → 按 Tab
inn Live Template if (变量 != null) {} 非空 输入 inn → 按 Tab
.if Postfix if (条件) {} 条件判断 布尔表达式后输入 .if → 按 Tab 或 Enter
.else Postfix if (!条件) {} 或 else {} 取反判断 布尔表达式后输入 .else → 按 Tab 或 Enter
.null Postfix if (变量 == null) {} 判空 变量后输入 .null → 按 Tab 或 Enter
.notnull / .nn Postfix if (变量 != null) {} 非空判断 变量后输入 .nn → 按 Tab 或 Enter
.instanceof Postfix if (变量 instanceof 类型) {} 类型判断 变量后输入 .instanceof → 按 Tab 或 Enter
inst Live Template if (变量 instanceof 类型) {} 类型判断（Live Template 版） 输入 inst → 按 Tab
.try Postfix try { } catch (Exception e) {} try-catch 表达式后输入 .try → 按 Tab 或 Enter
.twr Postfix try (资源) {} try-with-resources 资源后输入 .twr → 按 Tab 或 Enter
.throw Postfix throw new Exception(); 抛出异常 表达式后输入 .throw → 按 Tab 或 Enter
.not Postfix !条件 取反 布尔表达式后输入 .not → 按 Tab 或 Enter
.assert Postfix assert 条件; 断言 表达式后输入 .assert → 按 Tab 或 Enter
.switch Postfix switch (变量) {} switch 语句 变量后输入 .switch → 按 Tab 或 Enter
test Live Template JUnit 测试方法模板 生成 @Test 方法 输入 test → 按 Tab
pr Live Template private 类型 变量; 快速声明私有字段 输入 pr → 按 Tab
psf Live Template public static final 类型 变量; 常量声明 输入 psf → 按 Tab
geti Live Template getter 方法 生成 getter 输入 geti → 按 Tab
seti Live Template setter 方法 生成 setter 输入 seti → 按 Tab
