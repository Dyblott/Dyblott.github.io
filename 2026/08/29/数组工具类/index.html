数组工具类

System类

  • src: 被复制的数组
  • srcPos: 被复制的数组开始复制的下标
  • dest: 目标数组
  • destPos: 目标数组开始粘贴的下标
  • length: 复制数组中多少个元素

Arrays类

方法 结构（典型方法签名） 说明
toString static String toString(int[] a) 返回数组内容的字符串表示形式（如 [1, 2, 3]），方便打印输出。
sort static void sort(int[] a) 对数组按数字升序进行排序（原地修改）。
binarySearch static int binarySearch(int[] a, int key) 使用二分法查找指定元素；必须先在有序数组中进行，找到返回索引，未找到返回负数。
copyOf static int[] copyOf(int[] original, int newLength) 复制数组，生成指定长度的新数组；长度超出原数组时，多余位置补默认值。

PS: 第三方工具类（ArrrayUtil）

方法 结构（典型方法签名） 说明
max static int max(int[] array) 返回数组中的最大值。
indexOf static int indexOf(int[] array, Object value) 顺序查找指定元素在数组中的位置，未找到返回 -1（即 INDEX_NOT_FOUND）。
reverse() static void reverse(int[] array) 将数组元素进行翻转（倒序排列，原地修改）。
