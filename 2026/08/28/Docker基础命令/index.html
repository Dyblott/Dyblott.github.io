2 容器和镜像

2.1 核心概念

当我们利用 Docker 安装应用时，Docker 会自动搜索并下载应用镜像（image）。镜像不仅包含应用本身，还包含应用运行所需要的环境、配置、系统函数库。Docker 会在运行镜像时创建一个隔离环境，称为容器（container）。

概念 说明
镜像（image） 将应用所需的运行环境、配置文件、系统函数库等与应用一起打包得到的就是镜像
容器（container） 为每个镜像的应用进程创建的隔离运行环境就是容器
镜像仓库（registry） 存储和管理镜像的平台。Docker 官方维护了一个公共仓库：Docker Hub（目前最大的镜像仓库）

架构：docker daemon（守护进程） 负责接收 docker run 等命令并管理镜像和容器。

2.2 命令解读

参数 说明
docker run 创建并运行一个容器
-d 让容器在后台运行
--name mysql 给容器起个名字，必须唯一
-p 3307:3306 设置端口映射（宿主机端口 : 容器内端口）
-e KEY=VALUE 设置环境变量
mysql:8 指定运行的镜像的名字、版本

接下来，可以通过jdbc:mysql://192.168.0.2:3307（宿主机 IP + 映射端口）连接数据库

2.3 镜像命名规范

镜像名称一般分两部分组成：[repository]:[tag]

部分 说明
repository 镜像名
tag 镜像的版本

例如：mysql:8 → repository = mysql，tag = 8

不指定 tag 时，默认为 latest。

3 docker常见命令

官方文档：https://docs.docker.com/

3.1 常见命令表

命令 说明
docker pull 镜像名 从镜像仓库拉取镜像
docker push 镜像名 推送镜像到镜像仓库
docker images 查看本地镜像列表
docker rmi 镜像名 删除本地镜像
docker run 创建并运行容器
docker stop 容器名 停止容器
docker start 容器名 启动已停止的容器
docker ps 查看运行中的容器（-a 查看全部）
docker rm 容器名 删除容器
docker logs 容器名 查看容器日志（-f 持续跟踪）
docker exec -it 容器名 bash 进入容器内部
docker build 根据 Dockerfile 构建镜像
docker save 将镜像保存为 tar 包
docker load 从 tar 包加载镜像
