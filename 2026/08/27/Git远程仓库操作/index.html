Git远程仓库操作

摘要：远程仓库操作核心命令包括git remote管理连接、git clone克隆、git fetch拉取、git pull拉取合并、git push推送；首次推送用git push -u origin main建立跟踪关系。

远程仓库概念

远程仓库是托管在网络上的 Git 仓库（如 Gitee、GitHub），用于团队协作。

git remote（管理远程仓库）

git fetch（拉取远程更新）

注意：git fetch 只下载到本地仓库，不自动合并到工作区。

git pull（拉取并合并）

git push（推送到远程）
