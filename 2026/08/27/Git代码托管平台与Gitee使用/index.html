Git代码托管平台与Gitee使用

摘要：主流Git代码托管平台有GitHub/Gitee/GitLab等，Gitee为国内首选；创建仓库后通过SSH公钥或HTTPS方式克隆，支持免密操作。

主流代码托管平台

平台 网址 特点
GitHub https://github.com 全球最大，开源首选
Gitee（码云） https://gitee.com 国内访问快，中文友好
GitLab https://gitlab.com 可自建，功能强大
Bitbucket https://bitbucket.org 与 Jira 集成好
Coding https://coding.net 腾讯云，DevOps 平台

注册 Gitee 账号

  • 访问 https://gitee.com
  • 点击「注册」
  • 填写手机号、邮箱、密码
  • 完成实名认证（推荐）

创建远程仓库

  1. 登录 Gitee → 点击右上角「+」→「新建仓库」
  2. 填写仓库信息：
    • 仓库名称：my-project
    • 仓库介绍：项目描述（可选）
    • 是否开源：公开 / 私有
    • 初始化仓库：
      • ✅ Add .gitignore（选择语言模板）
      • ✅ Add Readme File
      • ✅ Choose a License
  3. 点击「创建」

配置 SSH 公钥（推荐）

为什么要用 SSH？

  • HTTPS 每次推送都要输入密码
  • SSH 配置后免密推送，更安全

  1. 登录 Gitee → 设置 → SSH公钥
  2. 标题：自定义（如 “我的电脑”）
  3. 公钥：粘贴上面复制的公钥内容

HTTPS vs SSH

协议 格式 优点 缺点
HTTPS https://gitee.com/user/repo.git 简单，通用 需输密码
SSH git@gitee.com:user/repo.git 免密，安全 需配置密钥
