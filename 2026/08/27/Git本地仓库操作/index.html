Git本地仓库操作

摘要：本地仓库操作核心命令包括git add添加到暂存区、git commit提交、git status查看状态、git log查看历史、git diff对比差异、git reset/rm/mv撤销修改，以及.gitignore忽略文件配置。

工作目录流程图

git add（添加到暂存区）

git commit（提交到本地仓库）

git status（查看状态）

git log（查看历史）

格式占位符：

占位符 说明
%H 完整提交哈希
%h 简短提交哈希
%an 作者名
%ae 作者邮箱
%ad 作者日期
%ar 作者相对时间
%s 提交说明
%d 引用名称（如分支、标签）

git diff（差异比较）

git rm（删除文件）

git mv（移动/重命名文件）

git reset（撤销操作）

git revert（反向提交）

git restore（恢复文件）

.gitignore（忽略文件）

常用模板：https://github.com/github/gitignore
