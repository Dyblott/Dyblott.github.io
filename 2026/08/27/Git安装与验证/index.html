Git安装与验证

摘要：Git支持Windows/macOS/Linux三大平台，Windows推荐官网下载安装包或winget/scoop，验证安装用git –version，附带Git Bash常用命令速查。

Windows 安装

方式一：官网下载（推荐）

  • 访问官网：https://git-scm.com/download/win
  • 下载 Git for Windows 安装包（最新 2.53.0）
  • 双击安装，关键选项勾选：
    • ✅ Git Bash Here（右键菜单）
    • ✅ Git GUI Here
    • ✅ Use Git from the Windows Command Prompt
    • ✅ Use the OpenSSL library
    • ✅ Checkout Windows-style, commit Unix-style line endings
