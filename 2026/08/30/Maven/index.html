Maven

Maven介绍

java项目的构建和依赖管理的工具

  • 作用：

    • 构建

    • 清理—>编译–>测试–>报告–>打包–>安装–>部署

      • 阶段 含义 Maven 命令
        清理 删除 target mvn clean
        编译 编译主代码 mvn compile
        测试 执行单元测试 mvn test
        报告 测试报告生成 ✅ 自动在 test 阶段生成
        打包 打成 jar / war mvn package
        安装 安装到本地仓库 mvn install
        部署 发布到远程仓库 mvn deploy

    • 依赖管理

  • 好处：

    • 可以自动化完成编译、测试、打包、发布等流程，提升开发效率和交付质量

下载地址：https://maven.apache.org/

POM文件

打包类型

  • pom, jar, war 默认是jar,可省略不写
    • pom: 聚合/父工程, 多模块项目、依赖管理
    • jar: Java 普通包, 工具类、公共模块、Spring Boot
    • war: Web 应用包, 传统 Web 项目、部署到 Tomcat

依赖

坐标（GAV）

  • 每个项目都有的唯一标识
    • groupId: 公司、部门、事业部
    • artifactId: 项目会被拆成很多模块，模块化
    • version: 版本
