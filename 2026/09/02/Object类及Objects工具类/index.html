方法介绍

方法 作用 对象为 null 时的行为
equals(a, b) 安全比较相等 不抛异常，返回 false
deepEquals(a, b) 深度比较（数组） 不抛异常
hashCode(o) 获取 hashCode 返回 0
toString(o) 调用 toString 返回 "null" 字符串
toString(o, 默认值) 带默认值的 toString 返回指定的默认值
isNull(o) 判断是否为 null 返回 true
nonNull(o) 判断是否不为 null 返回 false
requireNonNull(o) 要求非 null 抛 NullPointerException
