注解

注解 作用
@Data 组合注解：getter、setter、toString、equals、hashCode
@NoArgsConstructor 无参构造
@AllArgsConstructor 全参构造
@RequiredArgsConstructor 给final字段生成构造器，业务高频
@Builder 建造者模式，链式构建对象
@Getter/@Setter 单独生成 get/set
@Slf4j 自动生成 log 日志对象 log.info()

Junit

JUnit 是 Java 单元测试框架，现在主流 JUnit5(Jupiter)，旧版本 JUnit4 逐步淘汰。

Maven添加依赖

测试代码放在 src/test/java，scope=test，打包不会带入。

Junit5核心注解

注解 说明
@Test 标记这是单元测试方法
@BeforeEach 每个测试方法执行前运行
@AfterEach 每个测试方法执行后运行
@BeforeAll 所有测试执行前，只执行 1 次；方法必须 static
@AfterAll 所有测试执行完成后，执行 1 次；方法必须 static
@Disabled 忽略该测试，不执行
@DisplayName("测试名字") 自定义测试显示名称
