网络编程

1. 网络编程是什么

让设备和设备之间能互相”聊天”——把你的程序通过网络发给另一台设备，让它收到并处理。

两种架构对比：

架构 客户端 服务端 特点
CS 需要开发安装 需要开发 体验好，功能强大
BS 浏览器代替 需要开发 无需安装，浏览器访问即可

2. 网络编程三要素

通信离不开三个东西：IP、端口号、传输协议。

3. IP 地址

IP（Internet Protocol） 是上网设备的唯一标识。

类型 说明
IPv4 32位，点分十进制（如 192.168.1.66），已用完
IPv6 128位，冒分十六进制，可为万物编号

特殊 IP：

地址 说明
127.0.0.1 / localhost 本机回环地址，永远只代表本机

常用命令：

DNS（域名解析）：把域名（www.baidu.com）解析成 IP 地址，用户不用记数字。

4. InetAddress 类

Java 用 InetAddress 类表示 IP 地址。

方法 说明
getByName(String host) 根据主机名/域名获取 IP
getHostName() 获取主机名
getHostAddress() 获取 IP 地址字符串

5. 端口号

端口号是应用程序在设备中的唯一标识，范围 0 ~ 65535。

范围 说明
0 ~ 1023 知名端口（HTTP 80、HTTPS 443）
1024+ 自用端口，推荐使用

⚠️ 一个端口只能被一个应用程序占用。

6. 传输协议

UDP（User Datagram Protocol）

特点 说明
面向无连接 发之前不握手，直接扔数据
速度快 不等确认
有大小限制 一次最多 64KB
数据不安全 可能丢包

场景：视频直播、语音通话、广播——丢几帧无所谓，速度优先。

TCP（Transmission Control Protocol）

特点 说明
面向连接 先三次握手建立连接
速度慢 要确认
无大小限制 可靠传输
数据安全 不丢包、不乱序

场景：发邮件、文字聊天、下载、支付——必须准确。

9. 三次握手与四次挥手

三次握手（建立连接）

为什么是三次？

  • 第1次：客户端告诉服务端我要连接
  • 第2次：服务端回”我同意”，同时告诉客户端我也准备好了
  • 第3次：客户端确认”收到”，双方都确认对方能收到自己的消息

四次挥手（断开连接）

为什么挥手需要四次？

  • TCP 是全双工（两边都能同时发），所以每边都要单独说”我说完了”
  • 中间多了一次 ACK，确认服务端收到”客户端要断开”

10. 本章小结

要素 说明
IP 设备唯一标识，127.0.0.1 是本机
端口号 应用唯一标识，065535，01023 留给系统
UDP 无连接、快、不安全、最大64KB
TCP 面向连接、安全、可靠、三次握手建立、四次挥手断开
UDP 类 DatagramSocket + DatagramPacket
TCP 类 客户端 Socket，服务端 ServerSocket.accept()
