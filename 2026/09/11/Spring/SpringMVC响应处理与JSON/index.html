SpringMVC 响应处理与 JSON

1. 响应方式总览

SpringMVC 中 Controller 方法可以返回多种类型，框架自动处理响应：

返回类型 效果
String + @ResponseBody 直接写字符串到响应体
String（无 @ResponseBody） 当作视图名，走视图解析器跳转页面
Object / List / Map 自动转 JSON 写回（需要 @ResponseBody 或 @RestController）
void 默认走请求转发（Servlet 方式）
ModelAndView 手动指定视图名 + 模型数据

3. 返回对象和 List（自动转 JSON）

这是前后端分离开发中最常用的方式。SpringMVC 会自动把返回值转成 JSON 字符串，浏览器收到的是 JSON 数据。

原理：spring-boot-starter-web 内置了 Jackson，当方法有 @ResponseBody 或在 @RestController 类中时，返回对象会自动走 JSON 转换。

6. 转发与重定向

6.1 核心区别（面试常问）

对比项 转发（forward） 重定向（redirect）
次数 1 次请求 2 次请求
地址栏 不变 变
数据共享 ✅ request 可以共享 ❌ request 数据丢失
浏览器感知 无感知（服务端行为） 有感知（浏览器发新请求）
跨域 ❌ 不能跨域 ✅ 可以跨域

6.2 转发（forward）

服务端内部跳转，浏览器地址不变，一次请求完成。

6.3 重定向（redirect）

告诉浏览器发新请求，地址栏变，数据不共享。

场景 返回类型 关键注解/类
