Thymeleaf 模板语法

1. Thymeleaf 是什么

Thymeleaf 是 Spring Boot 官方推荐的模板引擎，用来在 HTML 页面里嵌入后端数据，生成动态页面（服务端渲染）。

为什么用它替代 JSP：

对比 JSP Thymeleaf
打开方式 必须服务器才能看 浏览器直接打开也能看静态效果（自然模板）
语法 <% %> 脚本混杂 th:* 属性，HTML 友好
Spring 整合 需额外配置 Spring Boot 自动配置
前端协作 差 好（HTML 即模板）

3. 标准表达式（四大核心）

表达式 语法 作用 示例
变量表达式 ${...} 取变量/共享域数据 ${user.name}
选择变量表达式 *{...} 配合 th:object 简化取属性 *{name}
链接表达式 @{...} 生成 URL（自动加上下文路径） @{/user/list}
消息表达式 #{...} 国际化消息 #{welcome.msg}
片段表达式 ~{...} 引入片段模板 ~{common :: header}

4. 常用 th:* 属性

4.1 文本与值

属性 作用 示例
th:text 转义文本（HTML 特殊字符会被转义，防 XSS） <span th:text="${name}">
th:utext 不转义文本（原样输出 HTML） <span th:utext="${html}">
th:value 表单输入框的值 <input th:value="${user.name}">
th:attr 通用属性设置 <img th:attr="src=${img},title=${t}">

5. 共享域取值（混合开发核心）

共享域 取值语法 说明
Request 域 ${key} 单次请求有效
Session 域 ${session.key} 会话内有效
ServletContext 域 ${application.key} 全应用有效
Model ${key} 本质也是 Request 域

6. 内置对象与工具方法

Thymeleaf 提供一批内置工具对象（以 # 开头），方便在模板里做格式化。

对象 用途 示例
#dates 日期格式化 #dates.format(date, 'yyyy-MM-dd')
#numbers 数字格式化 #numbers.formatDecimal(num, 1, 2)
#strings 字符串处理 #strings.toUpperCase(name)
#lists 集合操作 #lists.size(list)、#lists.isEmpty(list)
#arrays 数组操作 #arrays.length(arr)
#maps Map 操作 #maps.size(map)
#objects 对象判断 #objects.nullSafe(obj, '默认')
#request 原生 request #request.getContextPath()
#session 原生 session #session.id
#servletContext 原生 context #servletContext.contextPath

10. 常见错误与解决

错误现象 原因 解决
页面显示 ${user.name} 原文 没引命名空间或文件不在 templates 下 加 xmlns:th、放对目录
报 500 模板找不到 Controller 返回的视图名拼错 检查返回值与文件名一致
${session.x} 取不到 没往 Session 存数据 用 session.setAttribute()
中文乱码 没设 charset <meta charset="UTF-8"> + 配置编码
标签里写 ${} 被当字符串 用了 th:text 但值是字面量 值里用变量要 ${}，纯文本直接写
3.1+ 无法访问 #request 安全限制默认关闭 用 Controller 传值替代

11. 语法速查表

语法 含义
${x} 变量表达式
*{x} 选择变量（配合 th:object）
@{/path} 链接表达式
#{key} 国际化消息
~{tpl :: frag} 片段表达式
th:text / th:utext 文本（转义/不转义）
th:value 表单值
th:each 遍历
th:if / th:unless 条件
th:switch / th:case 分支
th:href / th:src / th:action 链接/资源/表单
th:class / th:style 样式
th:selected / th:checked 下拉/复选
th:block 无渲染容器
[[x]] / [(x)] 行内表达式
th:fragment / th:replace / th:insert 片段复用
