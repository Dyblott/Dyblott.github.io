SpringMVC 注解

1. 注解总览（按功能分类）

分类 注解
控制器标识 @Controller、@RestController、@ControllerAdvice、@RestControllerAdvice
请求映射 @RequestMapping、@GetMapping、@PostMapping、@PutMapping、@DeleteMapping、@PatchMapping
参数接收 @PathVariable、@RequestParam、@RequestBody、@RequestHeader、@CookieValue、@ModelAttribute
响应 @ResponseBody、@ResponseStatus
异常处理 @ExceptionHandler
跨域 @CrossOrigin
数据绑定 @InitBinder、@SessionAttributes、@Valid、@Validated

2. 控制器标识注解

2.1 @Controller

标记一个类为控制器，方法返回值当作视图名（走模板引擎渲染页面）。

2.2 @RestController

等价于 @Controller + 类里每个方法都加 @ResponseBody，返回值直接作为响应体（自动转 JSON），用于前后端分离接口。

2.3 @ControllerAdvice / @RestControllerAdvice

全局增强注解，标注的类可统一处理：异常（@ExceptionHandler）、数据绑定（@InitBinder）、全局数据（@ModelAttribute）。

  • @ControllerAdvice：返回值默认走视图（适合需要跳转页面的全局处理）
  • @RestControllerAdvice：返回值直接写响应体（适合返回 JSON 的全局异常处理器）

3. 请求映射注解

3.1 @RequestMapping

最通用的映射注解，把一个 URL 映射到方法。核心属性：

属性 作用 示例
value / path URL 路径 @RequestMapping("/user")
method 限制请求方法 method = RequestMethod.POST
params 限制必须有某参数 params = "name"
headers 限制请求头 headers = "Content-Type=application/json"
consumes 限制请求体格式 consumes = "application/json"
produces 限制响应体格式 produces = "application/json"

3.2 快捷映射注解（推荐）

注解 等价 语义
@GetMapping @RequestMapping(method=GET) 查询
@PostMapping @RequestMapping(method=POST) 新增
@PutMapping @RequestMapping(method=PUT) 全量更新
@DeleteMapping @RequestMapping(method=DELETE) 删除
@PatchMapping @RequestMapping(method=PATCH) 部分更新

4. 参数接收注解

4.1 @PathVariable（路径参数）

接收嵌在 URL 路径里的值（RESTful 风格）。

4.2 @RequestParam（查询参数）

接收 URL ?key=value 参数，可控制必填和默认值。

4.3 @RequestBody（请求体）

接收请求体里的 JSON，自动反序列化为 Java 对象（前后端分离新增/更新必用）。

4.4 @RequestHeader（请求头）

4.5 @CookieValue（Cookie）

4.6 @ModelAttribute

两种用法：

  1. 标注方法：在每次请求前执行，预存公共数据到 Model
  2. 标注参数：把表单参数批量绑定到对象（等价于直接写实体类形参）

5. 响应注解

5.1 @ResponseBody

标注方法返回值直接写入响应体（不走视图解析器），配合 @Controller 使用；@RestController 已内置此注解。

5.2 @ResponseStatus

为异常处理或接口指定 HTTP 状态码。

6. 异常处理注解

6.1 @ExceptionHandler

捕获并处理指定异常，可标注在普通 Controller（局部）或 @ControllerAdvice 类（全局）。

匹配规则：就近匹配，子类异常写前面，父类（Exception）写最后兜底。

7. 跨域注解

7.1 @CrossOrigin

允许跨域访问（前后端分离联调常用）。

也可全局配置（见《SpringMVC静态资源与视图》的 CORS 章节）。

8. 数据绑定注解

8.1 @InitBinder

在 Controller 或 @ControllerAdvice 中预处理请求参数，如日期格式化、禁止某些字段绑定。

8.2 @SessionAttributes

把 Model 中的指定数据存到 Session（跨多个请求共享）。

8.3 @Valid / @Validated（参数校验）

配合 JSR-303 校验注解（@NotNull、@NotBlank、@Size 等）验证参数。

@Valid 和 @Validated 区别：@Validated 支持分组校验，@Valid 支持嵌套对象校验，日常用 @Valid 即可。

9. 注解速查表

注解 位置 作用
@Controller 类 标记为控制器，返回视图
@RestController 类 控制器 + 方法返回 JSON
@ControllerAdvice 类 全局增强（异常/绑定/数据）
@RestControllerAdvice 类 全局增强，返回 JSON
@RequestMapping 类/方法 通用 URL 映射
@GetMapping 方法 GET 映射
@PostMapping 方法 POST 映射
@PutMapping 方法 PUT 映射
@DeleteMapping 方法 DELETE 映射
@PatchMapping 方法 PATCH 映射
@PathVariable 参数 路径参数
@RequestParam 参数 查询参数（必填/默认值）
@RequestBody 参数 JSON 请求体
@RequestHeader 参数 请求头
@CookieValue 参数 Cookie
@ModelAttribute 方法/参数 预存数据/表单绑定
@ResponseBody 方法/类 返回值写响应体
@ResponseStatus 方法/异常类 指定 HTTP 状态码
@ExceptionHandler 方法 捕获异常
@CrossOrigin 类/方法 允许跨域
@InitBinder 方法 参数预处理
@SessionAttributes 类 Model 数据存 Session
@Valid / @Validated 参数 参数校验
