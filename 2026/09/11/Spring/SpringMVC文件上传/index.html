SpringMVC 文件上传

1. 文件上传原理

文件上传本质是把浏览器端的文件数据通过 HTTP 请求体发送到服务器，服务器接收并写入磁盘或云存储。

8. 常见错误与解决

错误 原因 解决
MissingServletMultipartResolver 没引入文件上传依赖或没配置 导入 spring-boot-starter-web（含 Commons FileUpload）
文件大小超限 超过 max-file-size 调大配置或提示用户
上传后访问 404 静态资源路径没配 配置 addResourceHandlers 映射上传目录
文件名乱码 中文文件名乱码 file.getOriginalFilename() 在 Spring Boot 中已自动处理
空指针 file.isEmpty() 没判断 上传前一定要判空

9. 总结

知识点 核心要点
上传原理 enctype="multipart/form-data" + POST，文件在请求体中
单文件上传 MultipartFile + transferTo()
多文件上传 MultipartFile[] 或 List<MultipartFile>
配置限制 max-file-size / max-request-size
安全校验 非空检查、大小限制、类型限制、生成 UUID 防重名
本地存储 按日期分目录 + 配置静态资源映射
云存储 生产推荐 OSS/COS，自动 CDN 加速
