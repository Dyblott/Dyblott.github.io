十七、.gitignore 推荐

快速使用清单

  1. 复制 pom.xml 依赖，执行 mvn clean install。
  2. 把 common / security / modules 包结构按目录树建好。
  3. 复制 application.yml + logback-spring.xml 到 resources。
  4. 实现 UserDetailsService，login 接口即可跑通 JWT 登录。
  5. 所有 Controller 返回 Result<T>，异常交给 GlobalExceptionHandler。
  6. 用 LoginContext.getUserId() 取当前用户，用 Assert 做业务校验。
  7. 启动后访问 /doc.html 查看接口文档。

生产环境务必：① 修改 jwt.secret 为强随机串；② 把 token 存 Redis 做可主动失效；③ 数据库连接与日志级别放到 application-prod.yml 并用 --spring.profiles.active=prod 启动。
