MySQL DQL 查询

概述

DQL（Data Query Language） 是 SQL 中用于查询数据的语言，核心就是 SELECT 语句。

虽然 DQL 字面上是 DML（数据操作）的子集，但因查询功能复杂、语法多样，习惯单独归为 DQL。

子句 关键字 说明
基础 SELECT、FROM 查哪些字段、从哪张表
条件 WHERE 行级过滤
分组 GROUP BY、HAVING 分组聚合
排序 ORDER BY 结果排序
限制 LIMIT 分页

⚠️ SQL 书写顺序 ≠ 执行顺序，执行顺序为：
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT

二、条件查询（WHERE）

1. 比较运算符

运算符 说明
= 等于
<> / != 不等于
> < >= <= 大小比较
BETWEEN ... AND ... 闭区间范围
IN (值列表) 在列表内
LIKE 模糊匹配
IS NULL / IS NOT NULL 判空

运算符 说明
AND / && 与
OR / || 或
NOT / ! 非

3. 典型示例

⚠️ = 不能判断 NULL：WHERE dept_id = NULL 永远查不出数据，必须用 IS NULL。

三、排序查询（ORDER BY）

  • ASC：升序（默认）
  • DESC：降序
  • 多字段排序：先按字段1排序，相同再按字段2排序

ORDER BY 是查询语句最后执行的子句，所以可以用 SELECT 中的别名：ORDER BY 年薪 DESC。

四、聚合函数

聚合函数对一组值进行计算，返回单个值。

函数 说明 是否统计 NULL
COUNT(字段) 统计行数 ❌ 不统计 NULL
COUNT(*) 统计行数（含 NULL） ✅ 包含 NULL
SUM(字段) 求和 ❌ 忽略 NULL
AVG(字段) 平均 ❌ 忽略 NULL
MAX(字段) 最大值 ❌ 忽略 NULL
MIN(字段) 最小值 ❌ 忽略 NULL

COUNT(*) 统计总行数，COUNT(字段) 忽略 NULL。判断字段值”全表有多少行”用 COUNT(*)。

3. WHERE 和 HAVING 的区别

对比项 WHERE HAVING
时机 分组前 分组后
作用 行级过滤 组级过滤
过滤对象 原始数据行 聚合结果
能否用聚合函数 ❌ 不能 ✅ 能

WHERE 中不能出现聚合函数。例如 WHERE COUNT(*) > 5 是错的。

4. SELECT 后的字段约束

SELECT 后只允许出现：

  • 分组字段本身
  • 聚合函数
  • 常量

否则数据无意义。

六、分页查询（LIMIT）

  • 起始索引从 0 开始（第一行索引 = 0）
  • 第 N 页的 SQL：LIMIT (N-1) * 每页条数, 每页条数

LIMIT 必须写在 SQL 的最后。

七、多表查询

1. 笛卡尔积（了解即可，避免直接使用）

2. 内连接（INNER JOIN）

只查两张表中连接字段相等的记录。

3. 外连接

类型 关键字 行为
左外连接 LEFT JOIN 保留左表所有记录，右表无匹配则填 NULL
右外连接 RIGHT JOIN 保留右表所有记录，左表无匹配则填 NULL

实际开发中左外连接用得最多，因为习惯上以”主体表”为左表。

4. 自连接

表自己连接自己，常用于查上下级、父子关系。

5. 联合查询（UNION）

把多条 SELECT 的结果合并成一个结果集。

2. 列子查询（结果是一列多行）

3. 行子查询（结果是一行多列）

4. 表子查询（结果是多行多列）

九、查询语句执行顺序（重要）

顺序 子句 作用
1 FROM 选表、起别名
2 JOIN ... ON 多表连接
3 WHERE 行级过滤
4 GROUP BY 分组
5 HAVING 组级过滤
6 SELECT 选字段、聚合
7 DISTINCT 去重
8 ORDER BY 排序
9 LIMIT 分页

易错点：

  • 字段别名只能在 SELECT 之后才能用，所以 WHERE 里不能引用 SELECT 中的别名
  • ORDER BY 可以引用 SELECT 中的别名（因为它在 SELECT 之后执行）
