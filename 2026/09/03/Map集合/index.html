Map 集合

Map 概述

Map 是双列集合的顶级接口。每个元素由 key（键） 和 value（值） 两部分构成，构成键值对。

特点：

  • key 唯一，value 可重复
  • key 和 value 都必须是引用类型（基本类型自动装箱）
  • 一个 key 对应一个 value

实现类： HashMap、LinkedHashMap、TreeMap、Hashtable、Properties

HashMap

特点： 无序、无索引、key 唯一、value 可重复、线程不安全、可以存 null 键和 null 值，数据结构为哈希表。

常用方法：

方法 说明
V put(K key, V value) 添加键值对（key 重复则 value 覆盖，返回被覆盖的 value）
V get(Object key) 根据 key 获取 value（不存在返回 null）
V remove(Object key) 根据 key 删除键值对，返回被删除的 value
boolean containsKey(Object key) 判断是否包含指定 key
boolean containsValue(Object value) 判断是否包含指定 value
int size() 键值对个数
void clear() 清空所有键值对

扩容机制（需背下来）：

  • 数组默认长度 16，加载因子 0.75（数组使用率达到 75% 时扩容）
  • 每次扩容 2 倍
  • 当链表长度 ≥ 8 且数组容量 ≥ 64 时，链表转化为红黑树（JDK 8+）
  • 红黑树节点数 ≤ 6 时，退化为链表

LinkedHashMap

特点： 有序（按插入顺序）、无索引、key 唯一、value 可重复、线程不安全、数据结构为哈希表 + 双向链表。

是 HashMap 的子类，用双向链表维护插入顺序。

Map 的遍历方式

方式一：先取 key，再通过 key 取 value

方式二：同时获取 key 和 value（推荐）

Map.Entry 是 Map 的内部接口，表示一个键值对。entrySet() 将所有键值对取出存入 Set 集合。

TreeMap

特点： 可对 key 排序、无索引、key 唯一、value 可重复、线程不安全、数据结构为红黑树。

  • TreeMap() → 按 key 的自然排序（ASCII 码）
  • TreeMap(Comparator<? super K> comparator) → 按指定规则排序

TreeMap 的 key 不能为 null（因为需要做排序比较）。

Hashtable

特点： 无序、无索引、key 唯一、value 可重复、线程安全、不能存 null 键和 null 值，数据结构为哈希表。

⚠️ Hashtable 是早期遗留类，线程安全但效率低。现已不推荐使用，线程安全场景推荐 ConcurrentHashMap。

与 HashMap 对比：

对比项 HashMap Hashtable
线程安全 ❌ 不安全 ✅ 安全（synchronized）
null 支持 可存 null 键和 null 值 ❌ 不允许
出现版本 JDK 1.2（更新） JDK 1.0（遗留）
效率 高 低

Properties

特点： 是 Hashtable 的子类，key 和 value 固定为 String，线程安全，唯一能和 IO 流结合使用的集合，用于解析配置文件。

特有方法：

方法 说明
void setProperty(String key, String value) 存键值对
String getProperty(String key) 根据 key 获取 value
Set<String> stringPropertyNames() 获取所有 key（类似 keySet）
void load(InputStream in) 从流中加载键值对
void store(OutputStream out, String comments) 写入流并保存

读取配置文件（xxx.properties）：

配置文件用于存放”硬数据”（如数据库账号密码、接口地址等），避免直接写在代码中，改动时只改配置文件，不改源码。

Map 保证 key 唯一的原理

Set 集合底层依赖 Map 存储（存在 key 的位置），因此 Set 保证元素唯一、Map 保证 key 唯一的原理完全相同：

必须让 key 重写 hashCode 和 equals 方法。

流程：先比较哈希值，再比较内容。 哈希值不同直接存；哈希值相同则比较内容，内容相同则去重复，内容不同则存。

练习：统计字符串中每个字符出现的次数

思路：

  1. 遍历字符串每个字符
  2. 用字符作 key 去 Map 中查找
  3. 若 key 不存在 → 存入 key=字符, value=1
  4. 若 key 存在 → value +1 后重新存入

各 Map 实现类对比

实现类 有序 线程安全 null 键 null 值 数据结构
HashMap ❌ ❌ ✅ 允许 ✅ 允许 哈希表
LinkedHashMap ✅ 插入顺序 ❌ ✅ 允许 ✅ 允许 哈希表+双向链表
TreeMap key 排序 ❌ ❌ 不允许 ✅ 允许 红黑树
Hashtable ❌ ✅ ❌ 不允许 ❌ 不允许 哈希表
Properties ❌ ✅ ❌ 不允许 ❌ 不允许 哈希表
