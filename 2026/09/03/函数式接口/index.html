函数式接口

概念

函数式接口：有且仅有一个抽象方法的接口。

可以用 @FunctionalInterface 注解来强制校验，编译器会检查接口是否真的只有一个抽象方法。

使用前提： Lambda 表达式、函数式接口的方法引用都必须基于函数式接口。

四大内置函数式接口

Java 在 java.util.function 包下提供了四个最常用的函数式接口：

接口 抽象方法 含义 场景
Supplier<T> T get() 供给型 无输入，返回一个值
Consumer<T> void accept(T t) 消费型 接收一个值，进行操作
Function<T,R> R apply(T t) 功能型 接收 T，返回 R（类型转换）
Predicate<T> boolean test(T t) 判断型 接收 T，返回 boolean

Supplier —— 供给型接口

T get() 方法，无参数，返回一个指定类型的值。

Consumer —— 消费型接口

void accept(T t) 方法，接收一个值进行”消费”（操作），无返回值。

“消费”就是”操作”，具体怎么操作取决于 accept 方法的实现。

Function —— 功能型接口

R apply(T t) 方法，接收 T 类型的参数，返回 R 类型的结果，常用于类型转换。

Predicate —— 判断型接口

boolean test(T t) 方法，接收 T 类型参数，返回 boolean，常用于条件过滤。

filter 方法的底层正是 Predicate，所以 stream.filter(s -> s.length() > 3) 实际上是传入了一个 Predicate 实现。

方法引用

方法引用是 Lambda 表达式的进一步简化写法。当 Lambda 表达式的方法体中只是调用一个已有的方法时，可以直接用方法引用替代。

格式： 对象::方法名 或 类名::方法名

使用条件（需同时满足）：

  1. 被引用的方法在重写方法的方法体中被调用
  2. 被引用方法的参数列表和返回值与重写方法一致
  3. 去掉 Lambda 参数和 ->，将 . 改成 ::

方法引用详解

1. 对象名 —— 引用成员方法

println(String s) 的参数和返回值与 Consumer.accept(String s) 完全一致。

2. 类名 —— 引用静态方法

Math.random() 无参返回 Double，与 Supplier.get() 一致。

3. 类名 —— 引用构造方法

Person(String name) 构造方法的参数和返回值（返回 Person 对象）与 Function.apply 一致。

4. 数组类型 —— 引用数组构造

int[]::new 的效果等价于根据长度创建数组。

方法引用总结表

引用方式 格式 示例
对象引用成员方法 对象::成员方法名 System.out::println
类引用静态方法 类名::静态方法名 Math::random
类引用构造方法 类名::new Person::new
数组类型引用 数组类型[]::new int[]::new

核心技巧：观察 Lambda 方法体中调用的是哪个方法，参数和返回值是否与函数式接口的抽象方法一致，一致即可改写为方法引用。
