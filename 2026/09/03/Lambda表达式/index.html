省略维度 **规则说明 完整写法（匿名/Lambda初始） 极简写法（最终形态）
前置转换 函数式接口才可用；删掉 new 接口(){重写方法名，加 -> new Thread(new Runnable() { @Override public void run() { System.out.println("ok"); } }).start(); new Thread( () -> System.out.println("ok") ).start();
参数类型 编译器可推断类型，类型必省 (String s) -> System.out.println(s) s -> System.out.println(s)
参数括号 单参数时，小括号 () 可省；无参/多参必须留 () (s) -> System.out.println(s) s -> System.out.println(s)
方法体(无返回) 单行代码，大括号 {} 和分号 ; 可省 () -> { System.out.println("hi"); } () -> System.out.println("hi")
方法体(有返回) 单行返回，大括号、分号、return 三者同省 (a, b) -> { return a + b; } (a, b) -> a + b
