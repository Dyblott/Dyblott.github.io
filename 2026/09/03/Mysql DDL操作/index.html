MySQL DDL 操作

概述

DDL（Data Definition Language） 是 SQL 中用来定义/管理数据库对象结构的语言，对象包括：

  • 数据库（DATABASE）
  • 表（TABLE）
  • 索引（INDEX）
  • 视图（VIEW）

核心关键字：CREATE（创建）、DROP（删除）、ALTER（修改）、SHOW（查看）、TRUNCATE（清空表）。

DDL 操作隐式提交事务，执行后立即生效，不能 ROLLBACK。

二、数据类型（重点）

1. 数值类型

类型 字节 范围（有符号） 用途
TINYINT 1 -128 ~ 127 状态、标记位
INT 4 ±21 亿 主键、计数（最常用）
BIGINT 8 极大值 雪花 ID、大数据量主键
DECIMAL(M,D) 可变 精确小数 金额（M 总位数，D 小数位）

金额字段严禁用 FLOAT / DOUBLE，因为浮点数有精度损失。统一用 DECIMAL(10,2)。

2. 字符串类型

类型 特点 场景
CHAR(n) 定长，n 字节以内自动空格补齐 手机号、身份证、定长编码
VARCHAR(n) 变长，最多 n 字符 姓名、邮箱、标题、内容
TEXT 长文本（最大 65KB） 文章正文、备注

CHAR vs VARCHAR：CHAR 查询略快、浪费空间；VARCHAR 节省空间但需要 1-2 字节存长度。状态型短字段用 CHAR，可变长字段用 VARCHAR。

3. 日期类型

类型 格式 范围 备注
DATE YYYY-MM-DD 1000-01-01 ~ 9999-12-31 生日
DATETIME YYYY-MM-DD HH:MM:SS 同上 最常用，默认 NOT NULL 时用 8 字节
TIMESTAMP 同上 1970-01-01 ~ 2038 4 字节，时区敏感，自动更新时间用
TIME HH:MM:SS -838:59:59 ~ 838:59:59 时长

推荐用 DATETIME 而非 TIMESTAMP（2038 年问题）。

三、约束（重点）

约束是用来对表中数据加限制条件，保证数据的完整性。

约束 关键字 说明
主键 PRIMARY KEY 唯一标识一行，非空且唯一，每张表只能有一个
唯一 UNIQUE 字段值不可重复，可以为 NULL（NULL 不算重复）
非空 NOT NULL 字段值不能为 NULL
默认 DEFAULT 值 不写入时使用默认值
自增 AUTO_INCREMENT 数值自动 +1，必须配合主键或唯一键使用
外键 FOREIGN KEY 引用另一张表的主键，建立表间关系
检查 CHECK（MySQL 8.0+） 限制字段值范围
无符号 UNSIGNED 让数值类型不能为负，扩展正数范围
